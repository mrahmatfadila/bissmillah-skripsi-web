# AI Instructions & Project Rules

1. **Commit & Push to GitHub**: Every completed modification must be committed with a clear message and pushed to the remote repository.
2. **Zero Database Data Loss**: NEVER delete, drop, truncate, or reset database tables/data.
3. **Strict UI & Feature Preservation**: NEVER modify, alter, redesign, or tamper with existing UI/UX designs, layouts, styling, or existing system features unless explicitly instructed by the user.
4. **Clean Code & High Performance**: All new or modified code must be clean, type-safe, lightweight, performant, and well-structured without unnecessary bloat.
